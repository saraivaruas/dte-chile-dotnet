# Documentos de referencia

Los documentos oficiales del SII (formato de DTE, instructivos, manuales) se descargan desde [sii.cl](https://www.sii.cl) a `docs/sii-pdf/`, que no se versiona.
Referencias usadas: «Formato Documentos Tributarios Electrónicos», manual OI2003_UPDTE_MDE (envío), OI2007_AUTAUTOM_MDE (autenticación),
Resolución Exenta N° 121 de 2026 y los esquemas XSD de `schemas/`.
